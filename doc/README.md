# GCG マリガン期待値計算 — 画面仕様書

| タブ | ファイル | 概要 |
|------|----------|------|
| デッキ編集 | [01_deck-editor.md](01_deck-editor.md) | デッキ作成・カード登録・コンボ管理 |
| 期待値     | [02_dashboard.md](02_dashboard.md)     | コスト期待値・初動安定率・キーカード確率・コンボ確率 |

## 共通仕様

- デッキは **50枚ちょうど** が必要（期待値・テストドロー・統計タブの利用条件）
- デッキは localStorage に最大 **5件** 保存
- 同一カードNo. は最大 **4枚** まで
- 使用色は最大 **2色** まで
